Set up your free real-time backend in 2 minutes (Uses Cloud Firestore 100% free Spark plan):

1

Create a Firebase Project

Go to Firebase Console, click "Add Project" (e.g. pulse-chat-app).

2

Enable Cloud Firestore Database

Click Firestore Database → Create Database. Choose Start in Test Mode.

3

Enable Anonymous Authentication

Click Authentication → Get Started → Sign-in method → Enable Anonymous.

4

Copy App Credentials

Click ⚙️ Project settings → scroll to Your apps → Click Web </> → Copy the firebaseConfig keys.
